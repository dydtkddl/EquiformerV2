4. 핵심 모듈 (Core Modules)

SurfScreen의 모듈별 상세 기능과 사용법을 설명합니다.

4.1 Molecule 모듈

분자 구조를 생성, 로드, 조작하는 모듈입니다.

주요 클래스

from surfscreen import MoleculeBuilder # PubChem에서 분자 다운로드 mol = MoleculeBuilder.from_pubchem("acetone") # 파일에서 로드 mol = MoleculeBuilder.from_file("molecule.xyz") # SMILES에서 생성 mol = MoleculeBuilder.from_smiles("CC(=O)C") # 분자 정보 조회 print(f"원자 수: {mol.n_atoms}") print(f"질량: {mol.mass} amu") print(f"화학식: {mol.formula}") # 기하 최적화 mol.optimize(engine="xtb") # 저장 mol.save("optimized.xyz")

지원 입력 소스

소스메서드설명
PubChemfrom_pubchem(name)이름으로 검색 후 3D 구조 다운로드
파일from_file(path)XYZ, CIF, MOL 등 지원
SMILESfrom_smiles(smiles)RDKit으로 3D 구조 생성
ASE Atomsfrom_atoms(atoms)ASE 객체에서 직접 생성

4.2 Surface 모듈

금속/산화물 표면 슬랩을 생성하는 모듈입니다.

from surfscreen import SurfaceBuilder # 표면 생성 surf = SurfaceBuilder.create( element="Cu", miller=[1, 1, 1], supercell=(3, 3, 1), layers=4, vacuum=15.0 # Å ) # 표면 정보 print(f"밀러 지수: {surf.miller}") print(f"원자 수: {surf.n_atoms}") print(f"표면적: {surf.area} Å²") # 하층 고정 surf.fix_bottom_layers(2) # 저장 surf.save("surface.extxyz")

지원 원소

FCC: Cu, Au, Ag, Pt, Pd, Ni, Al, Rh, Ir

BCC: Fe, W, Mo, Ta, Cr, V

HCP: Ti, Zr, Hf, Mg, Zn, Co

4.3 Adsorption 모듈

흡착 시스템 및 구성 생성을 담당합니다.

AdsorptionSystem

from surfscreen.adsorption import AdsorptionSystem # 흡착 시스템 생성 ads = AdsorptionSystem(surface, molecule) # 사이트 감지 sites = ads.detect_sites() print(f"감지된 사이트: {len(sites)}") # top: 4, bridge: 4, hollow: 4 # 특정 위치에 분자 배치 ads.place_molecule( position=[5.0, 5.0, 12.0], rotation=[0, 0, 45] # degrees ) # 최적화 ads.optimize(engine="mace", fmax=0.05) # 흡착 에너지 계산 E_ads = ads.get_adsorption_energy() print(f"E_ads = {E_ads:.3f} eV")

AdsorptionGenerator

from surfscreen.adsorption import AdsorptionGenerator # 구성 생성기 gen = AdsorptionGenerator(surface, molecule) # 구성 생성 configs = gen.generate_configurations( rotations=[0, 45, 90, 135], heights=[2.0, 2.5], max_configs=100 ) # 겹침 필터링 valid = gen.filter_overlapping(min_distance=1.5) print(f"유효 구성: {len(valid)}") # 저장 gen.save_configs("configs/") # HTML 미리보기 gen.visualize_html("preview.html")

4.5 MD Engine 모듈

from surfscreen.md import MDEngine, MDConfig # 설정 config = MDConfig( ensemble="nvt", # nvt, npt, nve temperature=300.0, # K timestep=1.0, # fs steps=10000, thermostat="langevin", engine="mace", device="cuda" ) # MD 실행 md = MDEngine(atoms, config, output_dir="md_output") summary = md.run() # 결과 print(f"총 시간: {summary['total_time_fs']} fs") print(f"평균 온도: {summary['avg_temperature_K']:.1f} K")

4.6 Analysis 모듈

구조, 동역학, 열역학 분석 도구입니다.

구조 분석

from surfscreen.analysis import StructuralAnalyzer analyzer = StructuralAnalyzer(atoms, n_surface_atoms=64) height = analyzer.calculate_adsorption_height() # Å tilt = analyzer.calculate_tilt_angle() # degrees site = analyzer.classify_site_type() # "top"/"bridge"/"hollow"

동역학 분석

from surfscreen.analysis import DynamicsAnalyzer analyzer = DynamicsAnalyzer("trajectory.traj", timestep=1.0) # MSD 및 확산계수 msd = analyzer.calculate_msd("Li") diffusion = analyzer.calculate_diffusion("Li") print(f"D = {diffusion.D:.2e} cm²/s") # RDF rdf = analyzer.calculate_rdf(("Li", "O")) # 이온전도도 cond = analyzer.calculate_conductivity("Li", charge=1, temperature=300) print(f"σ = {cond.sigma:.2e} S/cm")

열역학 분석

from surfscreen.analysis import ThermodynamicAnalyzer thermo = ThermodynamicAnalyzer() thermo.load_from_directory("results/") boltzmann = thermo.calculate_boltzmann(temperature=300) print(f"최고 확률 구성: {boltzmann.names[0]}")
