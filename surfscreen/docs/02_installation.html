2. 설치 (Installation)

2.1 시스템 요구사항

최소 요구사항

구성요소 최소 권장
Python 3.9 3.10+
메모리 8 GB 32 GB+
디스크 10 GB 50 GB+
GPU (선택) CUDA 11.0+ CUDA 12.0+ / RTX 3090+

💡 권장 환경

최상의 성능을 위해 NVIDIA GPU가 있는 Linux 서버를 권장합니다. MACE 계산은 GPU에서 10배 이상 빨라집니다.

2.2 pip 설치

가장 간단한 설치 방법:

pip install surfscreen

GPU 지원을 위한 설치:

pip install surfscreen[cuda]

2.3 소스에서 설치

개발용 또는 최신 버전이 필요한 경우:

# 저장소 클론 git clone https://github.com/user/surfscreen.git cd surfscreen # 가상환경 생성 및 활성화 python -m venv venv source venv/bin/activate # Linux/Mac # venv\Scripts\activate # Windows # 개발 모드로 설치 pip install -e ".[dev]"

2.4 의존성 설치

핵심 의존성

SurfScreen이 자동으로 설치하는 패키지:

  • ase - Atomic Simulation Environment
  • numpy - 수치 계산
  • scipy - 과학 계산
  • click - CLI 프레임워크
  • rich - 터미널 출력
  • pymatgen - 재료 분석

선택적 의존성

# MACE ML 포텐셜 pip install mace-torch # xTB 계산기 pip install xtb # 시각화 (선택) pip install plotly

2.5 MACE 설정

MACE는 SurfScreen의 기본 계산 엔진입니다:

# MACE 설치 pip install mace-torch # GPU 지원 확인 python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}')"

MACE 모델 다운로드

첫 실행 시 자동으로 다운로드되거나, 수동 다운로드:

# 사전 훈련된 모델 사용 (자동 다운로드) # mace_mp("medium") - 중간 정확도, 빠름 # mace_mp("large") - 높은 정확도, 느림 # 또는 직접 다운로드 python -c "from mace.calculators import mace_mp; mace_mp(model='medium')"

⚠️ GPU 메모리

MACE large 모델은 최소 8GB GPU 메모리가 필요합니다. 메모리 부족 시 medium 또는 small 모델을 사용하세요.

2.6 설치 확인

설치가 올바른지 확인:

# 버전 확인 surfscreen --version # 도움말 표시 surfscreen --help # 계산 엔진 확인 surfscreen config show

예상 출력

$ surfscreen --version SurfScreen v0.2.0 $ surfscreen config show SurfScreen Configuration Available engines: ['mace', 'xtb'] Available elements: ['Cu', 'Au', 'Ag', 'Pt', 'Pd', 'Ni', ...]

✅ 설치 완료!

이제 빠른 시작으로 이동하여 첫 번째 스크리닝을 실행해보세요.
