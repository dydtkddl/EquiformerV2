5. CLI 명령 참조

SurfScreen의 모든 CLI 명령과 옵션을 설명합니다.

surfscreen [OPTIONS] COMMAND [ARGS]... Options: --version 버전 표시 --help 도움말 표시

molecule - 분자 관리

surfscreen molecule from-pubchem

PubChem에서 분자 다운로드

NAME 분자 이름 (예: acetone, ethanol)
-o, --output 출력 파일 (기본: molecule.xyz)
surfscreen molecule from-pubchem acetone -o acetone.xyz
surfscreen molecule from-file

파일에서 분자 로드

FILE 입력 파일 경로
-o, --output 출력 파일
--optimize 기하 최적화 수행

surface - 표면 관리

surfscreen surface create

금속 표면 슬랩 생성

ELEMENT 원소 기호 (Cu, Au, Pt, ...)
--miller 밀러 지수 (기본: 111)
--supercell 슈퍼셀 크기 (기본: 3x3x1)
--layers 원자층 수 (기본: 4)
--vacuum 진공 두께 Å (기본: 15.0)
--fix-layers 고정할 하층 수 (기본: 2)
-o, --output 출력 파일
surfscreen surface create Cu --miller 111 --supercell 3x3x1 --layers 4 -o Cu111.extxyz

screen - 스크리닝

surfscreen screen run

흡착 스크리닝 실행

-s, --surface 표면 파일 (필수)
-m, --molecule 분자 파일 (필수)
--engine 계산 엔진 (mace, xtb)
--model MACE 모델 (small, medium, large)
--rotations 회전 샘플 수
--heights 흡착 높이 (쉼표 구분)
--fmax 수렴 기준 (기본: 0.05)
-o, --output 출력 디렉토리
surfscreen screen run -s Cu111.extxyz -m acetone.xyz --engine mace -o results/
surfscreen screen results

스크리닝 결과 조회

RESULTS_DIR 결과 디렉토리
--top 상위 N개만 표시
surfscreen screen report

HTML 리포트 생성

RESULTS_DIR 결과 디렉토리
-o, --output 출력 파일 (기본: report.html)
surfscreen screen report results/ -o report.html

adsorb - 흡착 구성

surfscreen adsorb generate

흡착 구성 사전 생성

-s, --surface 표면 파일
-m, --molecule 분자 파일
-r, --rotations 회전 각도 (쉼표 구분)
-H, --heights 높이 (쉼표 구분)
--max-configs 최대 구성 수
-o, --output 출력 디렉토리
surfscreen adsorb generate -s Cu111.xyz -m acetone.xyz -r 0,45,90,135 -H 2.0,2.5 -o configs/
surfscreen adsorb visualize

구성 HTML 미리보기

CONFIGS_DIR 구성 디렉토리
-o, --output 출력 HTML 파일

md - 분자 동역학

surfscreen md run

MD 시뮬레이션 실행

STRUCTURE 구조 파일
--ensemble 앙상블 (nvt, npt, nve)
-T, --temperature 온도 (K)
-P, --pressure 압력 (bar, NPT only)
--timestep 시간 간격 (fs)
-n, --steps 스텝 수
--thermostat 열조절기 (langevin, berendsen)
--engine 계산 엔진
--device 디바이스 (cuda, cpu)
-o, --output 출력 디렉토리
surfscreen md run system.xyz --ensemble nvt -T 300 -n 10000 --engine mace -o md_output/
surfscreen md continue

체크포인트에서 재개

CHECKPOINT_DIR 체크포인트 디렉토리
-n, --steps 추가 스텝 수
surfscreen md status

MD 상태 확인

OUTPUT_DIR MD 출력 디렉토리

analysis - 분석

surfscreen analysis height

흡착 높이 분석

STRUCTURE 구조 파일
--n-surface 표면 원자 수 (0=자동)
surfscreen analysis msd

MSD 계산

TRAJECTORY 트라젝토리 파일
-s, --species 원자 종류 (예: Li)
--timestep 시간 간격 (fs)
-o, --output 출력 플롯
surfscreen analysis msd trajectory.traj -s Li -o msd.html
surfscreen analysis diffusion

확산 계수 계산

surfscreen analysis conductivity

이온 전도도 계산

-s, --species 이온 종류
-z, --charge 전하
-T, --temperature 온도 (K)
surfscreen analysis conductivity trajectory.traj -s Li -z 1 -T 300
surfscreen analysis rdf

RDF 계산

-p, --pair 원자 쌍 (예: Li-O)
surfscreen analysis rdf trajectory.traj -p Li-O -o rdf.html
surfscreen analysis boltzmann

Boltzmann 분포

RESULTS_DIR 결과 디렉토리
-T, --temperature 온도 (K)
surfscreen analysis boltzmann results/ -T 300 -o boltzmann.html

plot - 시각화

surfscreen plot energy-dist

에너지 분포 히스토그램

surfscreen plot energy-dist results/ -o energy.html
surfscreen plot correlation

상관관계 플롯

--x X축 속성
--y Y축 속성

config - 설정

surfscreen config show

현재 설정 표시

surfscreen config show
