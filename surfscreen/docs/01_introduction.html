1. 소개 (Introduction)

1.1 SurfScreen이란?

SurfScreen은 머신러닝 원자간 포텐셜(MLIP)을 활용한 엔터프라이즈급 표면 흡착 스크리닝 플랫폼입니다.

전통적인 DFT(밀도 범함수 이론) 계산은 정확하지만, 수백~수천 개의 흡착 구성을 스크리닝하기에는 너무 느립니다. SurfScreen은 MACE, EquiformerV2 같은 최신 MLIP를 활용하여 DFT 수준의 정확도로 초당 수십 개의 구성을 평가할 수 있습니다.

💡 핵심 가치

  • 속도: DFT 대비 1000배 이상 빠른 스크리닝
  • 정확도: DFT 수준의 에너지 정확도 (MAE < 50 meV)
  • 자동화: 사이트 감지부터 리포트 생성까지 완전 자동화
  • 확장성: GPU 가속, 병렬 처리 지원

1.2 왜 SurfScreen인가?

기존 방식의 문제점

문제 기존 방식 SurfScreen
계산 시간 구성당 수 시간 (DFT) 구성당 수 초 (MLIP)
사이트 선택 수동, 직관에 의존 자동 감지 및 분류
워크플로우 스크립트 직접 작성 CLI 명령 한 줄
결과 분석 별도 후처리 필요 자동 리포트 생성

1.3 주요 기능

🔬 다중 계산 엔진

MACE, xTB, CP2K, EquiformerV2 등 다양한 계산 엔진 지원

🎯 자동 사이트 감지

pymatgen 기반 top/bridge/hollow 사이트 자동 분류

⚡ GPU 가속

CUDA 지원으로 수십 배 성능 향상

📊 인터랙티브 리포트

3Dmol.js 기반 3D 시각화 및 분석 대시보드

🔄 MD 시뮬레이션

NVT/NPT/NVE 앙상블 분자 동역학

📈 분석 스위트

MSD, RDF, 확산계수, 이온전도도 계산

1.4 아키텍처

SurfScreen은 모듈식 아키텍처로 설계되어 확장이 용이합니다:

surfscreen/ ├── molecule/ # 분자 구조 관리 ├── surface/ # 표면 생성 및 관리 ├── adsorption/ # 흡착 시스템 및 구성 생성 ├── calculator/ # 계산 엔진 (MACE, xTB, ...) ├── screening/ # 스크리닝 워크플로우 ├── md/ # 분자 동역학 엔진 ├── analysis/ # 구조/동역학/열역학 분석 ├── visualization/ # 플롯 및 시각화 └── report/ # HTML 리포트 생성

1.5 표준 워크플로우

SurfScreen의 일반적인 사용 흐름:

  1. 표면 준비

    금속 표면 슬랩 생성 (예: Cu(111) 3×3×4)

  2. 분자 준비

    PubChem에서 다운로드 또는 직접 구조 파일 제공

  3. 구성 생성

    흡착 사이트, 회전, 높이 조합 자동 생성

  4. 스크리닝 실행

    MLIP로 모든 구성의 흡착 에너지 계산

  5. 결과 분석

    에너지 분포, Boltzmann 확률, 구조 분석

  6. 리포트 생성

    인터랙티브 HTML 리포트 자동 생성

1.6 사용 사례

🔋 배터리 전극 설계

고체 전해질 표면에서 리튬 금속의 흡착 거동을 스크리닝하여 안정적인 계면 형성 조건을 탐색합니다.

⚗️ 촉매 설계

반응 중간체의 흡착 에너지를 빠르게 평가하여 최적의 촉매 표면을 스크리닝합니다.

🧪 분자 센서

다양한 분자의 흡착 선택성을 비교하여 특정 분자에 민감한 센서 표면을 설계합니다.
