6. API 참조

SurfScreen Python API의 클래스와 메서드 참조입니다.

MoleculeBuilder

분자 구조를 생성하고 조작하는 클래스입니다.

class surfscreen.MoleculeBuilder

from surfscreen import MoleculeBuilder

클래스 메서드

메서드설명반환
from_pubchem(name: str) PubChem에서 분자 다운로드 MoleculeBuilder
from_file(path: str) 파일에서 분자 로드 MoleculeBuilder
from_smiles(smiles: str) SMILES에서 분자 생성 MoleculeBuilder
from_atoms(atoms: Atoms) ASE Atoms에서 생성 MoleculeBuilder

인스턴스 속성

속성타입설명
atomsase.AtomsASE Atoms 객체
n_atomsint원자 수
formulastr화학식
massfloat분자량 (amu)

인스턴스 메서드

메서드설명
optimize(engine: str, fmax: float = 0.05) 기하 구조 최적화
save(path: str) 파일로 저장
center() 질량 중심을 원점으로 이동

SurfaceBuilder

표면 슬랩을 생성하는 클래스입니다.

class surfscreen.SurfaceBuilder

클래스 메서드

메서드설명
create(element, miller, supercell, layers, vacuum) 표면 슬랩 생성
from_file(path: str) 파일에서 표면 로드

create() 파라미터

SurfaceBuilder.create( element: str, # 원소 기호 (Cu, Au, ...) miller: tuple, # 밀러 지수 (1, 1, 1) supercell: tuple, # 슈퍼셀 크기 (3, 3, 1) layers: int = 4, # 원자층 수 vacuum: float = 15.0 # 진공 두께 (Å) ) -> SurfaceBuilder

인스턴스 메서드

메서드설명
fix_bottom_layers(n: int) 하층 n개 고정 (FixAtoms constraint)
get_surface_atoms() 표면 원자 인덱스 반환
save(path: str) 파일로 저장

AdsorptionSystem

표면-분자 흡착 시스템을 관리합니다.

from surfscreen.adsorption import AdsorptionSystem ads = AdsorptionSystem(surface, molecule)

생성자

AdsorptionSystem( surface: SurfaceBuilder | Atoms, molecule: MoleculeBuilder | Atoms )

주요 메서드

메서드설명반환
detect_sites() 흡착 사이트 감지 List[Dict]
place_molecule(position, rotation) 분자 배치 None
optimize(engine, fmax) 기하 최적화 Dict
get_adsorption_energy() 흡착 에너지 계산 float (eV)
get_combined_atoms() 결합된 ASE Atoms 반환 Atoms

AdsorptionGenerator

흡착 구성을 자동 생성합니다.

from surfscreen.adsorption import AdsorptionGenerator, AdsorptionConfig gen = AdsorptionGenerator(surface, molecule)

주요 메서드

메서드설명
detect_adsorption_sites() 표면 사이트 자동 감지
detect_molecule_centers() 분자 중심 원자 감지
generate_configurations(rotations, heights, max_configs) 구성 생성
filter_overlapping(min_distance) 겹침 필터링
save_configs(output_dir, format) 구성 저장
visualize_html(output_path) HTML 미리보기 생성

CalculatorFactory

계산 엔진 팩토리입니다.

from surfscreen import CalculatorFactory calc = CalculatorFactory.create(engine="mace", model="medium", device="cuda")

create() 파라미터

파라미터타입설명
enginestr"mace", "xtb", "cp2k"
modelstrMACE: "small", "medium", "large"
devicestr"cuda" 또는 "cpu"

MDConfig

MD 시뮬레이션 설정 데이터클래스입니다.

from surfscreen.md import MDConfig config = MDConfig( ensemble="nvt", temperature=300.0, timestep=1.0, steps=10000, thermostat="langevin", engine="mace", device="cuda" )

속성

속성타입기본값설명
ensemblestr"nvt"nvt, npt, nve
temperaturefloat300.0온도 (K)
pressurefloat1.0압력 (bar)
timestepfloat1.0시간 간격 (fs)
stepsint10000총 스텝 수
thermostatstr"langevin"langevin, berendsen
barostatstr"berendsen"berendsen, pr
log_intervalint100로그 간격
checkpoint_intervalint1000체크포인트 간격
