8. 자주 묻는 질문 (FAQ)

설치 관련

Q: MACE 설치 시 CUDA 오류가 발생합니다

A: PyTorch와 CUDA 버전이 일치하는지 확인하세요:

# CUDA 버전 확인 nvidia-smi # PyTorch CUDA 버전 확인 python -c "import torch; print(torch.version.cuda)" # 필요 시 재설치 pip install torch --index-url https://download.pytorch.org/whl/cu121

Q: ASE와 pymatgen 버전 충돌이 발생합니다

A: 다음 순서로 설치하세요:

pip install ase==3.22.1 pip install pymatgen==2024.1.26 pip install surfscreen

Q: 가상환경 없이 설치할 수 있나요?

A: 가능하지만 권장하지 않습니다. 의존성 충돌을 피하기 위해 반드시 가상환경을 사용하세요:

conda create -n surfscreen python=3.10 conda activate surfscreen pip install surfscreen

사용법 관련

Q: 어떤 파일 형식을 지원하나요?

A: ASE가 지원하는 모든 형식을 지원합니다:

  • 입력: xyz, extxyz, cif, poscar, mol, sdf
  • 출력: extxyz (권장), xyz, cif

Q: 여러 분자를 동시에 스크리닝할 수 있나요?

A: 현재는 한 번에 하나의 분자만 스크리닝됩니다. 배치 스크립트를 사용하세요:

for mol in molecule1.xyz molecule2.xyz molecule3.xyz; do surfscreen screen run -s surface.xyz -m $mol -o results/$(basename $mol .xyz)/ done

Q: 흡착 사이트가 감지되지 않습니다

A: 표면 파일에 cell 정보가 포함되어 있는지 확인하세요. extxyz 형식 사용을 권장합니다:

# Python에서 cell 확인 from ase.io import read atoms = read("surface.xyz") print(atoms.cell) # cell이 모두 0이면 문제 # 올바른 저장 from ase.io import write write("surface.extxyz", atoms)

성능 관련

Q: GPU 사용량이 낮습니다

A: 배치 크기를 늘리거나 병렬 처리를 활성화하세요. 원자 수가 적으면 GPU 효율이 떨어집니다.

# 환경변수로 배치 크기 설정 export MACE_BATCH_SIZE=8

Q: 메모리 부족 오류가 발생합니다

A: 원자 수가 많으면 메모리 사용량이 증가합니다. 해결 방법:

  • smaller MACE 모델 사용 (--model small)
  • supercell 크기 축소
  • CPU 모드 사용 (--device cpu)

Q: 스크리닝에 얼마나 걸리나요?

A: 시스템 크기와 하드웨어에 따라 다릅니다:

시스템GPUCPU
~50 atoms~5분~30분
~100 atoms~15분~2시간
~200 atoms~1시간~8시간

오류 해결

Q: "CUDA out of memory" 오류

A: GPU 메모리가 부족합니다:

# 다른 프로세스 확인 nvidia-smi # 메모리 정리 import torch torch.cuda.empty_cache() # CPU 모드로 전환 surfscreen screen run ... --device cpu

Q: "Cell has zero volume" 오류

A: 표면 파일에 unit cell 정보가 없습니다:

from ase.io import read, write from ase.build import fcc111 # 올바른 표면 생성 surf = fcc111("Cu", size=(3,3,4), vacuum=15.0) write("Cu111.extxyz", surf) # cell 정보 포함

Q: 최적화가 수렴하지 않습니다

A: fmax 값을 높이거나 최대 스텝 수를 늘리세요:

surfscreen screen run ... --fmax 0.1 --max-steps 500

초기 구조가 매우 불안정할 경우 먼저 xTB로 pre-optimization을 수행하세요.

고급 사용법

Q: 커스텀 MACE 모델을 사용할 수 있나요?

A: 네, 모델 경로를 직접 지정할 수 있습니다:

from surfscreen import CalculatorFactory calc = CalculatorFactory.create( engine="mace", model="/path/to/my_model.model", device="cuda" )

Q: DFT 검증은 어떻게 하나요?

A: CP2K 엔진을 사용하세요:

calc = CalculatorFactory.create( engine="cp2k", inp_file="cp2k.inp", pseudo_dir="/path/to/pseudopotentials" )

또는 상위 N개 구조만 DFT로 검증하는 것을 권장합니다.

Q: 결과를 다른 형식으로 내보낼 수 있나요?

A: JSON과 CSV 형식을 지원합니다:

# JSON 결과 cat results/results.json # CSV 변환 import json import pandas as pd with open("results/results.json") as f: data = json.load(f) df = pd.DataFrame(data["configurations"]) df.to_csv("results.csv", index=False)
