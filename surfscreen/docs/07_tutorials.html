7.1 Cu(111) 표면에 CO 분자 흡착

가장 기본적인 표면 흡착 스크리닝 예제입니다.

목표

  • Cu(111) 표면 생성
  • CO 분자 준비
  • 흡착 에너지 계산
  • 최적 흡착 구조 찾기

Step 1: 표면 생성

# CLI 사용 surfscreen surface create Cu --miller 111 --supercell 3x3x1 --layers 4 -o Cu111.extxyz # Python API from surfscreen import SurfaceBuilder surf = SurfaceBuilder.create( element="Cu", miller=(1, 1, 1), supercell=(3, 3, 1), layers=4, vacuum=15.0 ) surf.fix_bottom_layers(2) surf.save("Cu111.extxyz")

Step 2: 분자 준비

# CLI 사용 surfscreen molecule from-pubchem CO -o co.xyz # Python API from surfscreen import MoleculeBuilder mol = MoleculeBuilder.from_pubchem("carbon monoxide") mol.optimize(engine="xtb") mol.save("co.xyz")

Step 3: 스크리닝 실행

surfscreen screen run \ -s Cu111.extxyz \ -m co.xyz \ --engine mace \ --model medium \ --rotations 8 \ --heights 1.8,2.0,2.2 \ -o results/cu_co/

Step 4: 결과 분석

# 결과 조회 surfscreen screen results results/cu_co/ --top 5 # 리포트 생성 surfscreen screen report results/cu_co/ -o cu_co_report.html

7.2 다중 분자 배치 스크리닝

여러 분자를 한 번에 스크리닝하는 고급 워크플로우입니다.

시나리오

Pt(111) 표면에서 알코올 계열 분자들(메탄올, 에탄올, 프로판올)의 흡착 특성 비교

배치 스크립트

#!/bin/bash # batch_screen.sh SURFACE="Pt111.extxyz" MOLECULES=("methanol" "ethanol" "propanol") # 표면 생성 surfscreen surface create Pt --miller 111 --supercell 4x4x1 -o $SURFACE # 각 분자에 대해 스크리닝 for mol in "${MOLECULES[@]}"; do echo "Processing $mol..." # 분자 다운로드 surfscreen molecule from-pubchem "$mol" -o "${mol}.xyz" # 스크리닝 실행 surfscreen screen run \ -s $SURFACE \ -m "${mol}.xyz" \ --engine mace \ --rotations 12 \ -o "results/${mol}/" done echo "All screening complete!"

결과 비교

# Python으로 결과 비교 import json from pathlib import Path molecules = ["methanol", "ethanol", "propanol"] results = {} for mol in molecules: with open(f"results/{mol}/results.json") as f: data = json.load(f) results[mol] = min(data["configurations"], key=lambda x: x["energy"]) for mol, best in results.items(): print(f"{mol}: E_ads = {best['energy']:.3f} eV")

7.3 분자 동역학 시뮬레이션

MACE를 사용한 NVT MD 시뮬레이션입니다.

목표

  • 최적화된 구조에서 MD 시작
  • 300K에서 10ps 시뮬레이션
  • 트라젝토리 분석

Step 1: MD 실행

# 최적화된 구조에서 MD 시작 surfscreen md run optimized.xyz \ --ensemble nvt \ --temperature 300 \ --timestep 1.0 \ --steps 10000 \ --thermostat langevin \ --engine mace \ --device cuda \ -o md_300K/

Step 2: 상태 모니터링

# MD 진행 상태 확인 surfscreen md status md_300K/ # 출력 예시: # Step: 5000/10000 (50%) # Time: 5.0 ps # Temperature: 298.5 K # Energy: -123.456 eV

Step 3: 트라젝토리 분석

# MSD 계산 surfscreen analysis msd md_300K/trajectory.traj -s Li -o msd.html # RDF 계산 surfscreen analysis rdf md_300K/trajectory.traj -p Li-O -o rdf.html

7.4 고체 전해질 이온전도도 분석

MD 시뮬레이션에서 이온전도도를 계산하는 워크플로우입니다.

워크플로우

  1. 다양한 온도에서 MD 실행 (300K, 400K, 500K, 600K)
  2. 각 온도에서 MSD 계산
  3. 확산 계수 추출
  4. Arrhenius 플롯으로 활성화 에너지 계산

Python 스크립트

from surfscreen.md import MDEngine, MDConfig from surfscreen.analysis import DynamicsAnalyzer from surfscreen.visualization import create_arrhenius_plot from ase.io import read import numpy as np # 온도 범위 temperatures = [300, 400, 500, 600] diffusion_data = [] atoms = read("solid_electrolyte.xyz") for T in temperatures: # MD 설정 config = MDConfig( ensemble="nvt", temperature=float(T), timestep=1.0, steps=50000, # 50 ps engine="mace", device="cuda" ) # MD 실행 md = MDEngine(atoms.copy(), config, output_dir=f"md_{T}K") md.run() # 확산 계수 계산 analyzer = DynamicsAnalyzer(f"md_{T}K/trajectory.traj", timestep=1.0) result = analyzer.calculate_diffusion("Li") diffusion_data.append({ "temperature": T, "diffusion": result.D, "error": result.D_error }) print(f"{T}K: D = {result.D:.2e} cm²/s") # Arrhenius 플롯 create_arrhenius_plot( temperatures=[d["temperature"] for d in diffusion_data], diffusion_coefficients=[d["diffusion"] for d in diffusion_data], output_path="arrhenius.html" )

결과 해석

Arrhenius 플롯에서 기울기로 활성화 에너지(Ea)를 계산합니다:

# Ea = -slope × kB × ln(10) # 예: slope = -5000 K → Ea ≈ 0.43 eV
