3. 빠른 시작 (Quick Start)

3.1 개요

이 가이드에서는 Cu(111) 표면에 아세톤(acetone) 분자의 흡착을 스크리닝하는 전체 워크플로우를 5분 안에 완료합니다.

📋 준비물

  • SurfScreen 설치 완료 (설치 가이드)
  • MACE 또는 xTB 계산기 활성화
  • 인터넷 연결 (PubChem 다운로드용)

3.2 Step 1: 표면 생성

Cu(111) 표면 슬랩을 생성합니다:

surfscreen surface create Cu --miller 111 --supercell 3x3x1 --layers 4 -o Cu111.extxyz

옵션 설명

  • Cu - 원소 기호
  • --miller 111 - 밀러 지수
  • --supercell 3x3x1 - 슈퍼셀 크기 (3×3 표면, 1층 반복)
  • --layers 4 - 원자층 수 (일반적으로 3-5)
  • -o - 출력 파일명

✅ 결과

Cu111.extxyz 파일이 생성됩니다 (36개 Cu 원자).

3.3 Step 2: 분자 준비

PubChem에서 아세톤 분자를 다운로드합니다:

surfscreen molecule from-pubchem acetone -o acetone.xyz

또는 기존 파일을 사용:

surfscreen molecule from-file my_molecule.xyz -o molecule.xyz

지원 포맷

  • .xyz - XYZ 형식
  • .extxyz - Extended XYZ
  • .cif - CIF 형식
  • .mol - Mol 형식

3.4 Step 3: 스크리닝 실행

표면과 분자를 사용하여 흡착 스크리닝을 실행합니다:

surfscreen screen run \ -s Cu111.extxyz \ -m acetone.xyz \ --engine mace \ --model medium \ --rotations 4 \ --heights 2.0,2.5,3.0 \ -o results/

옵션 설명

옵션 설명 기본값
-s 표면 파일 (필수)
-m 분자 파일 (필수)
--engine 계산 엔진 mace
--model MACE 모델 크기 medium
--rotations 회전 샘플 수 (0°, 90°, ...) 4
--heights 흡착 높이 (Å) 2.0

실행 중 출력 예시

Found 12 sites: 4 top, 4 bridge, 4 hollow Generating configurations... Total: 144 configurations 🚀 Running screening... [████████████████████████████████████████] 144/144 (100%) ✅ Screening completed! Best: site_top_0_rot0_h2.0 (-1.234 eV) Output: results/

3.5 Step 4: 결과 분석

스크리닝 결과를 분석합니다:

# 결과 요약 surfscreen screen results results/ # 상위 10개 구성 surfscreen screen results results/ --top 10 # Boltzmann 분포 분석 surfscreen analysis boltzmann results/ -T 300 -o boltzmann.html

출력 예시

📊 Screening Results Summary Total configurations: 144 Valid configurations: 138 (95.8%) Energy range: -1.234 to -0.156 eV Top 5 Configurations: 1. site_top_0_rot0_h2.0 -1.234 eV 2. site_top_1_rot90_h2.0 -1.198 eV 3. site_bridge_0_rot45_h2.5 -1.156 eV 4. site_hollow_2_rot0_h2.0 -1.089 eV 5. site_top_2_rot180_h2.5 -1.045 eV

3.6 Step 5: 리포트 생성

인터랙티브 HTML 리포트를 생성합니다:

surfscreen screen report results/ -o report.html

브라우저에서 열기:

# Linux xdg-open report.html # Mac open report.html # Windows start report.html

리포트 기능

  • 📊 에너지 분포 차트
  • 🔬 3D 구조 시각화 (3Dmol.js)
  • 📈 사이트별 비교
  • 🎞️ 최적화 트라젝토리 재생
  • 📋 상세 데이터 테이블
